ℹ️ About CEARF-N

CEARF-N fuses memory (transition + session + popularity) with neural evidence (GRU4Rec) via a query-conditioned β gate. The gate predicts per-query blend coefficients from 14 features, trained on out-of-fold data. On heterogeneous domains (Diginetica, 45% short context), the gate outperforms fixed mixing. On homogeneous domains (Amazon, 0% short context), a global β suffices. Try different session lengths to see how β adapts!
